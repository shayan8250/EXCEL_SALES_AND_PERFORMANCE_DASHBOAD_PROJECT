# Excel Sales and Performance Dashboard Project

## Project Description

This project contains two Excel workbooks I created to practice Excel and show how it can help make sense of business data. One focuses on Excel tools and formulas. The other uses sales data to create a dashboard.

## Why I Created This Project

I wanted hands-on practice with Excel, from working with formulas to building summaries and charts. This project helped me learn how to organize data, calculate useful measures, and present results clearly. These skills can help people review sales, compare products and regions, and track returns.

## Project Workbooks

- **Advanced Excel Workbook:** Includes practice with formulas such as MAX and MIN, conditional logic, PivotTables, conditional formatting, and charts.
- **Sales Performance Dashboard:** Uses 31,500 sales records, with raw and organized data, sales and cost calculations, PivotTables, charts, and filters for exploring results.

## Skills Practiced

- Organizing and reviewing data
- Using formulas and conditional logic
- Summarizing data with PivotTables
- Applying conditional formatting
- Creating charts and dashboards
- Exploring data with filters and slicers

## Data Note

The sales data is sample data and is not identified as belonging to a specific company. Unit costs are sample estimates, so profit figures are for practice and illustration.
